# Healthcare Knowledge Repository

## Overview

This repository contains a structured knowledge repository
for a healthcare-based knowledge system.

The repository stores information about diseases, symptoms,
causes, risk factors, diagnostic tests, treatment methods,
prevention methods and affected body systems.

The purpose of this repository is to demonstrate how knowledge
from a real-world domain can be organized and made publicly
accessible using a cloud-based platform such as GitHub.

## Diseases Covered

The repository currently contains information about:

1. Malaria
2. Dengue
3. Tuberculosis
4. Influenza
5. Asthma
6. Diabetes
7. Hypertension
8. Pneumonia
9. Gastroenteritis
10. Migraine

## Features

- Structured healthcare knowledge
- Disease and symptom information
- Disease classification
- Search by symptoms
- Search by body system
- Search by disease category
- Search by risk factors
- Basic healthcare inference rules

## Technologies Used

- Python
- JSON
- Git
- GitHub

## Future Scope

The repository can be extended by adding more diseases,
symptoms, medical relationships, inference rules and an
interactive user interface.

It can also be integrated with a chatbot or AI-based
decision-support system.

## Disclaimer

This repository is created for educational purposes and is
not intended to provide medical diagnosis or treatment advice.
